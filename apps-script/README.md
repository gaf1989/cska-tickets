# Вход через Google-аккаунт (Apps Script)

1. Откройте таблицу «Билеты_сравнение» → «Расширения» → «Apps Script».
2. Замените содержимое `Code.gs` файлом `Code.gs` из этой папки.
3. «Файл (+) → HTML», назовите файл `Index` и вставьте содержимое `Index.html` из этой папки.
4. «Начать развёртывание → Новое развёртывание» → тип «Веб-приложение»:
   - «Выполнять от имени»: «Пользователь, открывающий веб-приложение»;
   - «У кого есть доступ»: «Все пользователи Google».
5. Нажмите «Начать развёртывание», разрешите доступ и скопируйте ссылку на веб-приложение.
6. В настройках доступа таблицы уберите «Все, у кого есть ссылка» (выберите «Ограничен доступ») и добавьте нужных людей по почте с ролью «Читатель». Тогда данные увидят только они.
7. Отключите публикацию таблицы в интернете («Файл → Поделиться → Опубликовать в интернете → Прекратить публикацию»).
