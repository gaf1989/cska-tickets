Прогноз для предстоящих матчей

Матчи

Нажмите на строку, чтобы добавить матч в сравнение на первом графике (до 6).

Категории: ПО — плей-офф; ТОП — Зенит, УНИКС, Локомотив(-Кубань), Динамо; остальные — «Обычный». Эталонные кривые взяты из столбцов «Средний / ТОП / Обычный / ПО» исходной таблицы. Дни без записей считаются днями без продаж. Данные берутся из листа «Матчи по дням» Google Таблицы (диапазон A1:ZZ45); новые блоки матчей справа подхватываются автоматически, плей-офф определяется по названию («Финал», «Полуфинал») и по датам. Прогноз выручки считается по средней цене билета, уже достигнутой у матча; к матчу цена обычно растёт, поэтому оценка осторожная. «Надёжность» зависит от доли продаж, набранной на сегодня: если на сегодня обычно продаётся меньше 10% итога, прогноз не выдаётся.
